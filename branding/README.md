# Branding

| Dosya | Kullanım |
|---|---|
| `logo_mark.svg`, `logo_mark_512.png` | Yalnızca simge (şeffaf) |
| `logo_horizontal_light.*` / `logo_horizontal_dark.*` | Simge + "quanta"; açık / koyu zemin için |
| `app_icon.svg`, `app_icon_1024.png` | Uygulama ikonu (yuvarlak kare) |
| `social_preview.png` | GitHub *Settings → Social preview* (1280×640) |
| `android/res/` | Android launcher ikonları; `tool/setup_android.sh` kopyalar |

**Kavram:** "Q" harfi + kilit deliği (kasa) + halkadan ayrılan tek bir nokta (kuantum / kanıtlanabilir tek bit).
Renkler: `#7C4DFF → #10D9C4` gradyan, zemin `#141B3D → #090D1F`.
Güvenli alan: adaptive ikonda simge, 108 dp tuvalin ~%52'sinde.
