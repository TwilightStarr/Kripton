# Katkı / Contributing

* Hata ve öneriler için issue açın; güvenlik açıkları için [SECURITY.md](SECURITY.md).
* Kod değişikliğinden önce `flutter analyze && flutter test` temiz geçmeli.
* **Kripto değişiklikleri** (algoritma, parametre, etiket, biçim) docs/CRYPTO.md ve docs/DATA.md ile
  birlikte güncellenmeli; mevcut etiket/kod numaraları **asla yeniden numaralanmaz** (geriye uyumluluk).
* Yeni kaynak dosyalara `// SPDX-License-Identifier: Apache-2.0` başlığı ekleyin.
* Katkınızı göndererek, onu Apache-2.0 altında lisanslamayı kabul etmiş olursunuz (Apache-2.0 §5).
* Test verilerine **gerçek** parola/hesap koymayın.
